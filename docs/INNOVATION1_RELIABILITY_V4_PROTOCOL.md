# 创新点一可靠性模型 V4 冻结协议

更新日期：2026-10-14

## 1. 目的和边界

V4 将 14 维候选可靠性模型从“留一对象交叉验证后全量重拟合”改为严格的对象级
训练、校准和测试三段协议。GT 只用于离线生成 `MSSD_n <= 0.1` 二值标签，在线输入
仍然只有 FoundPose/PnP、轮廓和 RGB-D/CAD 几何特征。

本协议不会覆盖 `tless_objects2_4_logistic_v3.json`。V3 继续作为历史基线；V4 输出到
新的实验目录，待测试结果验收后才决定是否复制为新的冻结在线模型。

## 4. 模型选择规则

训练集拟合特征标准化参数和 L2 逻辑回归权重。校准集搜索：

- `L2 = {0, 0.1, 1, 10, 100}`；
- 不平衡原始似然与类别平衡训练两种方案；
- 每个候选均只在校准集拟合仿射 logit/Platt 概率校准器；
- 先最小化校准集 Brier，再依次比较 log-loss、ECE；
- AUC 不参与概率尺度选择，因为正斜率校准不改变排序。

模型选定后才计算测试集 AUC、Brier、ECE、可靠性曲线、固定分母选择成功率和
risk-coverage。测试结果不得反向修改特征、标签阈值、超参数网格或对象划分。

## 5. 证据边界

对象 1–30 的 V3 输出在冻结本协议前已经存在并被查看。因此 V4 测试组是“从本协议
开始不参与调参的冻结留出组”，不能写成从未观察过的盲测。若需要更强的论文证据，
仍需第二数据集或协议冻结后采集的真实相机数据。
